CASO DE ESTUDIO · PYTHON · DATOS

GM Predict AI: datos confiables para modelos predictivos.

Proyecto de investigación y desarrollo en Python orientado al análisis de series temporales. Su etapa actual se concentra en la adquisición, paginación y validación de datos históricos, utilizando pruebas automatizadas para verificar el comportamiento de sus componentes.

Python Pytest Pandas CCXT OHLCV
Ver código en GitHub ↗ Explorar arquitectura
01 / PROBLEMA

Antes de predecir, hay que validar.

Los datos históricos pueden contener registros incompletos, intervalos inconsistentes o valores que requieren validación. GM Predict AI aborda esta etapa mediante componentes independientes que facilitan la comprobación de la integridad temporal y la consistencia de las series.
